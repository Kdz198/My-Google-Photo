## 🎯 Tổng quan mục tiêu
Bản cập nhật này tập trung vào việc tối ưu hóa quy trình upload đa phương tiện bằng cách cải thiện cơ chế xử lý `multipart/form-data` trên giao diện web. Đồng thời, hệ thống cũng được chuẩn hóa cấu trúc cấu hình và nâng cấp lên các thư viện web hiện đại hơn để đảm bảo tính ổn định và tương thích cao.

## ✨ Chi tiết thay đổi

### 🚀 Tính năng mới
- <kbd>41af63c</kbd> **Cấu hình môi trường**: Di chuyển đường dẫn API gốc (Backend Base URL) vào file `.env` để tăng tính linh hoạt khi triển khai.
- <kbd>5a7cc3b</kbd> **Tự động hóa dữ liệu**: Thêm annotation `@CreationTimestamp` vào trường `creationTime` để tự động ghi nhận thời gian tạo đối tượng media trong cơ sở dữ liệu.

### 🐛 Sửa lỗi
- <kbd>58033c3</kbd> **Xử lý upload Backend**: Chuyển đổi từ `@RequestPart` sang `@RequestParam` để đảm bảo tính tương thích và xử lý đúng định dạng multipart upload.
- <kbd>e7edf1d</kbd> **Tối ưu Frontend**: Đơn giản hóa cơ chế xử lý multipart upload và cải thiện quy trình quản lý header trong các yêu cầu gửi lên server.
- <kbd>dcfd4c0</kbd> **Xây dựng Body thủ công**: Triển khai cơ chế xây dựng thủ công multipart body để loại bỏ sự phụ thuộc vào Browser API, giúp tăng tính ổn định trên nhiều trình duyệt.
- <kbd>5f6db99</kbd> **Tương thích kiểu dữ liệu**: Sử dụng `@JS` extension type cho việc nạp `FormData blob`, đảm bảo mã nguồn biên dịch thành công.
- <kbd>9ae1261</kbd> **Xử lý FormData**: Sử dụng `callMethod` để thực hiện `FormData.append` với dữ liệu blob và sửa lỗi chuyển đổi `buffer.toJS`.
- <kbd>7693c60</kbd> **Nâng cấp thư viện Web**: Thay thế `dart:html` bằng `package:web` nhằm tuân thủ các chuẩn hiện đại trong phát triển Flutter Web cho tính năng multipart upload.

### 🛠 Bảo trì hệ thống
- <kbd>1c57a91</kbd> **Cấu hình dự án**: Đăng ký `ui-ux-pro-max` làm kỹ năng dự án cho Claude Code để hỗ trợ tự động hóa trong tương lai.
- <kbd>3da460b</kbd> **Format mã nguồn**: Tự động định dạng code toàn bộ dự án bằng công cụ Spotless để đảm bảo tuân thủ chuẩn style guide.
